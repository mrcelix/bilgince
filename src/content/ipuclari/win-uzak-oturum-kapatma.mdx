```cmd
query session /server:sunucu01
logoff 3 /server:sunucu01
```

`query session` çıktısındaki ilk sütun oturum kimliğidir. `Disc` durumundaki oturumlar bağlantısı kopmuş ama hâlâ kaynak tüketen oturumlardır.

PowerShell tarafında:

```powershell
quser /server:sunucu01
```

Bağlantısı kopan oturumların otomatik kapanması için sunucuda **oturum sınırlarını** (idle ve disconnected timeout) grup ilkesiyle ayarlayın; elle kapatmak kalıcı çözüm değildir.
