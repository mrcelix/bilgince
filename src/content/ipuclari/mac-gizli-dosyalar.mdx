Finder penceresindeyken **Cmd + Shift + . (nokta)** gizli dosyaları gösterir; aynı tuş tekrar gizler.

Kalıcı olarak açmak isterseniz:

```bash
defaults write com.apple.finder AppleShowAllFiles -bool true
killall Finder
```

Bir dosyanın tam yolunu almak için Finder'da seçip **Cmd + Option + C** yapın — yol panoya kopyalanır. Yalnızca adı için `Cmd + C` yeterlidir.

Finder'ın alt kısmındaki yol çubuğunu açmak da işe yarar: **Görünüm → Yol Çubuğunu Göster**. Oradaki klasörlere çift tıklayarak hızlıca yukarı çıkabilirsiniz.
