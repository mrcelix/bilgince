Mevcut makinede kurulu uygulamaları dışa aktarın:

```powershell
winget export -o .\uygulamalar.json --accept-source-agreements
```

Yeni makinede:

```powershell
winget import -i .\uygulamalar.json --accept-package-agreements --accept-source-agreements
```

Tek tek kurmak için `winget install Microsoft.PowerShell` yeterlidir. Tümünü güncellemek: `winget upgrade --all`.

Dışa aktarma yalnızca winget kaynaklarında bulunan uygulamaları listeler; kurumsal MSI'lar listede çıkmaz.
