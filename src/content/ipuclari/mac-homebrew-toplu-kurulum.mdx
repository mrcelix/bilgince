Mevcut makinede kurulu her şeyi dışa aktarın:

```bash
brew bundle dump --file=~/Brewfile --describe --force
```

`--describe` her satıra ne olduğunu yazar; altı ay sonra listeye baktığınızda işinize yarar.

Yeni makinede:

```bash
brew bundle install --file=~/Brewfile
```

Brewfile yalnızca komut satırı araçlarını değil, `cask` ile masaüstü uygulamalarını ve `mas` ile App Store uygulamalarını da kapsar.

Bakım için düzenli çalıştırın:

```bash
brew update && brew upgrade && brew cleanup
brew bundle cleanup --file=~/Brewfile   # listede olmayanları gösterir
```

Son komut, zamanla biriken ve kimsenin hatırlamadığı paketleri ortaya çıkarır.
