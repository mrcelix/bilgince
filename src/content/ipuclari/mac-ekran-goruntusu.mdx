- **Cmd + Shift + 3** — tüm ekran
- **Cmd + Shift + 4** — seçtiğiniz alan
- **Cmd + Shift + 4, sonra Boşluk** — imleçle seçtiğiniz pencere (gölgeli, temiz kenarlı)
- **Cmd + Shift + 5** — kayıt paneli: ekran videosu, zamanlayıcı ve kaydetme yeri seçenekleri

Herhangi birine **Ctrl** eklerseniz dosya oluşmaz, doğrudan panoya kopyalanır: `Cmd + Ctrl + Shift + 4`.

Varsayılan kayıt yerini değiştirmek için:

```bash
defaults write com.apple.screencapture location ~/Resimler/Ekran
killall SystemUIServer
```

Pencere gölgesini kaldırmak isterseniz `defaults write com.apple.screencapture disable-shadow -bool true`.
