Durumu ve şifreleme ilerlemesini görmek:

```bash
fdesetup status
```

`FileVault is On.` yeterli değil — büyük disklerde ilk şifreleme saatler sürer ve o süre boyunca disk tam korumalı değildir. İlerleme yüzdesi de bu çıktıda görünür.

Kurtarma anahtarını kimin tuttuğunu kontrol edin:

```bash
sudo fdesetup list
sudo fdesetup hasinstitutionalrecoverykey
```

Kurumsal ortamda anahtarın MDM'e yedeklenmiş olması gerekir. Yalnızca kullanıcıda duran bir kurtarma anahtarı, kullanıcı ayrıldığında diski kalıcı olarak erişilemez yapar.

Yeni bir kurtarma anahtarı üretmek (eskisini geçersiz kılar):

```bash
sudo fdesetup changerecovery -personal
```
